# Available Resources

Network access is disabled. The supplied resources are the gallery images, partial sketches, descriptions, training and validation pairs, model weights and installed tools. No external embedding, reranking, generation, image-search, dataset or model service is available.

CLIP ViT-B/32 weights, tokenizer and image processor are at `/task/models/clip/`. Model files are read-only. The encoders remain fixed; optional scoring or fusion components may be adapted within the limits in the task instruction. Training and validation labels are development inputs.
