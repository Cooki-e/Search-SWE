# Available Resources

Network access is disabled. Use only the data, model checkpoints, Python packages and system tools already present in the task environment. Do not obtain external checkpoints, datasets, labels or services.

The embedding backbone is available at `/task/models/multilingual-e5-large`. The additional generative model at `/task/models/Qwen3.5-9B` is available for local use; using it is optional. Both model directories are read-only. No external API credentials are provided.
