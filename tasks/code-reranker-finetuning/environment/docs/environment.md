# GPU Environment

The shared CUDA 13.0 / Python 3.12 image includes CUDA-enabled PyTorch, Transformers, NumPy, requests, sentence-transformers, and standard build tools; use `/opt/conda/bin/python`. One NVIDIA GPU, 8 CPUs, 32 GiB RAM, and 100 GiB storage are available. The read-only mounts are `/task/data/corpus.jsonl`, `/task/data/train.jsonl`, `/task/models/bge-reranker-base`, `/task/models/bge-base-en-v1.5`, and `/task/docs`. No public validation data are provided; you may hold out training records locally. The frozen embedding checkpoint is supplied alongside the reranker. The fixed first stage combines local BM25 Top-200 and local BGE embeddings Top-200 by RRF; its formula and mining policy are in `available_resources.md`. Write the trained model to `/app/output/model`; do not alter `/task`. Both task phases use `no-network`; no task API keys are injected. Hugging Face/Transformers offline mode is enabled, and model loaders must use the local paths. The permitted resources and inference policy are described in `available_resources.md`.

An editable training baseline is installed under `/app/starter/`; invoke `train.sh` to train and export the checkpoint. See its README for defaults and a bounded smoke test.
